# 📊 SkillNexis – Data Science Internship

## Week 1: Excel & Data Cleaning

### 📌 Project Overview
This project is part of my Data Science with Python Internship at Skill Nexis.

The objective of this assignment is to understand data cleaning, data analysis, statistical calculations, and data visualization using Microsoft Excel.

### 🛠️ Tools Used
- Microsoft Excel
- Excel Formulas
- Pivot Tables
- Conditional Formatting
- Data Visualization

### ✅ Tasks Completed

**1. Data Cleaning**
- Checked and removed duplicate records.
- Identified missing values.
- Handled missing Postal Code values by replacing them with "Not Provided".

**2. Region-wise Sales Analysis**
- Created a summary of total sales for each region.

**3. Statistical Analysis**
- Calculated Mean, Median, and Mode using Excel formulas.

**4. Top 10 Sales**
- Identified the top 10 highest sales values.
- Applied conditional formatting to highlight top sales.

**5. Category-wise Revenue**
- Created a category-wise revenue summary.
- Designed a bar chart for data visualization.
